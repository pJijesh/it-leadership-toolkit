# One-page board IT report: template

## How to use this template

**Purpose.** A single page a director can read in three minutes and act on. It reports by exception, shows the same measures every month so trends are visible, and ends with the decisions you need.

**Guidance**

- Lead with the overall status and a two or three sentence headline. State the bad news first.
- Use the same layout every month. Directors learn where to look.
- Report a small, stable set of measures (eight to twelve) chosen from the [KPI catalogue](../03-kpi-pack/kpi-catalogue.md). Show the target next to each result.
- Take spend figures from the same source as finance, and reconcile them before the report goes out. Show variance as outturn against budget.
- Every Amber or Red needs one sentence on cause and one on what is being done.
- Put decisions last, numbered, each with a recommendation. If there are no decisions, say so.
- Keep it to one page. Put detail in an appendix that the reader can ignore.
- Use plain English. Spell out acronyms on first use.

**RAG definitions** (adapt to your own policy)

| Status | Meaning |
|---|---|
| Green | On plan. No action needed from the board. |
| Amber | A risk to plan exists. Management has an action in hand. The board is informed. |
| Red | Plan will be missed without a board decision or additional support. |

A worked example, with the PDF render, is in [example-northwind-board-report.md](example-northwind-board-report.md) and [../docs/board-report-example.pdf](../docs/board-report-example.pdf). The HTML source ([example-northwind-board-report.html](example-northwind-board-report.html)) can be adapted and printed to PDF from any browser.
